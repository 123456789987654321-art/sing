# 诗出有名

米色纸张风格的选字拼诗闯关小游戏。直接用浏览器打开 `index.html` 即可，无需安装依赖或构建。

## 玩法

- 诗途共有六级：执笔小书生 → 略通诗中韵 → 能诗亦善对 → 出口便成诗 → 诗才已出众 → 诗中之俊杰。学习模式每一类算一本，首次学完该类全部作品升一级，完成单篇或重复学习同一本不重复升级；第六级封顶。每次晋级自动弹出宣纸、诗字徽章与朱色印章风格的奖励弹窗，展示新称号，可点击「继续学习」、关闭按钮或按 Esc 关闭。等级自动保存在当前浏览器，独立于手动学习存档，切换模式、重新开始和刷新页面均保留；浏览器禁用存储时仅在当前页面有效。
- 入口提供「学习模式」「挑战模式」两个板块。学习模式分为诗经、楚辞、汉赋、唐诗、宋词、元曲，每轮随机排列完整作品。选书后先展示当前作品全文供记忆，点击旁边的「开始挑战」才进入逐句拼诗；整篇完成后可回顾全文，点击「下一篇」先预习下一篇。手动保存会保留当前处于预习还是拼诗阶段。
- 学习模式每本书的一轮学习中，完成第 4、8、12……首诗后触发「墨魇 · 守卷之战」。开场以宣纸、墨绿守卷妖、朱印和横幅提示强敌来袭；刚学完的四首各随机抽两句，再将八句整体打乱。按诗名、作者和原诗句序拼字，答对八句获胜；Boss 战独立提供六颗心，答错扣一颗，耗尽可重试，已学作品不丢失。战斗自动保存题序、爱心和已填文字，关闭或刷新后可继续。击败 Boss 后才可进入下一篇；若恰逢全书最后一篇，晋级奖励在战胜后发放。
- 挑战模式的「帮助」第一次直接填入诗名与作者输入框，第二次填入诗句前半句，第三次补全整句，三次后按钮改为「换一句」，可换另一句尚未使用的诗句；答对、切章或本章重来后重置。帮助从本章未答过的诗句中选取，不另设上方提示框。右侧答对记录按「诗句《诗名》—作者」合为一行，较长内容可横向查看。
- 挑战模式提供四季、节日、气候、花木、动物、乐器、品格七篇，共 48 个子章节。先点击篇章旁的「进入」，查看竖排书简目录，再点击「开始挑战」。各篇关卡循环推进，每章接受符合对应主题的真实诗句，优先本地校验；本地未收录时尝试联网核对原文。普通关卡累计答对第 10、20、30、40 句时，分别触发五言、七言、四言、杂言 Boss；答错或同一章重复出招不计数，本章爱心耗尽重来仍保留累计正确数。每场 Boss 写对三句不同的完整诗句及诗名、作者即可获胜，不限制主题；Boss 诗句不计入下一轮十句。五言、七言、四言要求每个分句对应字数；杂言要求一句内各分句字数不齐，以题库原文分句校验。Boss 直接在正常战斗页出现，共用怪物、墨障条和生命显示，无单独挑战弹窗；有独立六颗心，失败可重试，未击败不能跳过；只保留当前轮进度，刷新后重新开始。击败第四位 Boss 后通关。Boss 同样提供诗名作者、前半句、后半句三步帮助。
- 每次有效攻击都有淡墨笔划、朱砂伤害字和轻微受击反馈，适用于学习、挑战和两种 Boss 战；减少动态效果的系统设置下保留简洁数字反馈。攻击同步播放短促的挥剑与命中音效，击败敌人时追加收尾音，使用浏览器合成，无需下载音频。音效默认开启，右上角可静音并记住设置。首页仅保留学习与挑战两个模式，晋级弹窗以「原称号 → 新称号」显示变化。

- 学习模式按句号分句（问号、叹号也作为句末），逗号、分号等标点直接显示，每个汉字一个框。例如《静夜思》先填「床前明月光，疑是地上霜。」的 10 个字框，再填后一句。
- 挑战模式填写完整诗句、诗名和作者后提交；提示位于右侧「已答对的诗句」卡片上方，怪物气泡只显示对战台词。所有攻击按钮统一为「以诗出招」。
- 学习模式不按字数过滤正文，长句、短句都保留，字框和候选字块随句子长度生成；小屏自动换行。重复字提供足够数量的独立块。
- 拼对后点击「以诗出招」。伤害 =（诗句字数 − 本句帮助补字数）× 2，无其他伤害加成。
- 「帮助」每次补正一个字，并固定该位置。补出的字不计伤害；撤回、重选不会退回帮助消耗。
- 「床前明月光」不使用帮助为 10 点伤害，帮助一次为 8 点，全部帮助为 0 点。
- 点已选的字可撤回；「重选」清除手动选择。出招时逐字校验，只在上方句子框中将错误位置标红，下方选词区不标红；改字后清除该位置标记。每次错误出招扣 1 颗爱心，仍可修改重试。
- 两种模式均有 6 颗爱心。连续 3 句使用帮助，或单句帮助字数大于自行填写字数，扣 1 颗爱心；帮助字数恰好一半不扣爱心，同句两条规则同时触发只扣 1 颗。连续帮助每满 3 句重新计数，完全自行拼对一句会中断计数。
- 怪物不再自动扣除生命，击败怪物也不会恢复爱心；爱心用完结束本轮，重新开始恢复 6 颗爱心。
- 帮助按钮位于题目右上角，悬停或键盘聚焦时显示指向按钮的气泡：「每使用一次帮助，对应的字即失去攻击力。」。右侧诗文栏初始只显示当前诗名和作者，每次确认正确后才追加该句，每句保持一行。常见长句自动缩小字号，特别长的句子可横向查看；手机显示在战斗区下方。
- 四季篇怪物血量依次为 24、32、40、48。每次拼对后换题，帮助消耗随新题重置。学习模式小妖每轮 24 点血量，小妖血量归零不会跳过本篇未完成的句子。
- 各篇按所选篇章推进，重来保留所选篇章。支持返回模式选择、重新开始、音效开关、玩法弹窗与手机布局。切换模式或重来会取消未完成的攻击动画结算。
- 气泡与小妖共用布局容器，气泡保持在背景前方、贴近小妖且不相互遮挡。

## 文件

- `index.html`：页面结构
- `style.css`：响应式布局、纸张风格、CSS 小妖和动画
- `layout.css`：桌面宽屏与场景布局
- `tiles.css`：文字块、拼句槽、选字控件及紧凑布局
- `modes.css`：模式选择、篇章预览、错误高亮及气泡与小妖布局
- `boss.js` / `boss.css`：学习模式 Boss 的抽题、拼字战斗、存档和宣纸风格界面
- `challenge-boss.js`：挑战模式十句检查点、四种言数与三句 Boss 战
- `attack-fx.js` / `attack-fx.css`：共享攻击动画和清理逻辑
- `curriculum.js`：六类学习分类和七篇挑战章节配置
- `challenge-data-festivals-weather.js` / `challenge-data-plants-animals.js` / `challenge-data-instruments-virtues.js`：六个新增主题的诗句、作者与原文来源
- `poems.js`：六类学习诗文与四季篇题库（另含用于挑战的宋诗）
- `game.js`：出题、选字、帮助扣伤害、战斗和关卡逻辑

题目来自本地诗库。可在 `poems.js` 的 `POEMS` 数组中扩充诗句，并在 `curriculum.js` 中配置篇章主题、怪物与题目标题。当前开放七篇主题挑战。新增 138 条挑战诗句保存在三个 challenge-data 文件中，每条附原文来源；挑战专用题库独立于学习书目。内置作品无需网络即可游戏；题库外诗句需要联网核验。在线时会尝试加载 Noto Serif SC 字体，离线时使用系统宋体。当前答题位置在点击「保存进度」后保存在当前浏览器，已学完篇数会另行自动保存；再次进入同一分类会恢复作品顺序、当前句、已填文字和帮助状态、剩余爱心数量和连续帮助计数。未保存时重新进入会重新打乱作品顺序（仅一篇的分类顺序不变）。「新一轮」开始新的随机顺序，不会自动覆盖已保存的进度。挑战模式刷新后重新开始。

## 题库外诗句核验

'external-poetry.js' 使用维基文库公开 MediaWiki CORS API，检索作品后核对作品标题、作者栏和原文中的完整一句，匹配主题或 Boss 言数。只在证据充分时接受，不将搜索摘要、译者或注释当作原诗。采用 OpenCC 繁简词典，授权及来源见 'external-poetry-opencc-LICENSE.txt'。

网络超时、限流、未找到可靠原文或主题证据不足时，保留输入且不扣爱心；明确原文不匹配才算答错。该核验不能保证覆盖全部真实作品。请求有超时、会话缓存与取消保护，重来或返回后旧请求不会改变新一轮。帮助始终从未用过的本地候选中选择。

新增学习原文及逐篇来源记录在三个 'learning-data-*.js' 文件中，《湘夫人》句读与《木瓜》“琼玖”同步校正。旧测试入口和玩法已删除，过去已获得的称号保留。

## 验证

'node tests/learning-data.cjs' 与 'node tests/external-poetry.cjs' 可直接运行。浏览器回归脚本使用本地 Edge/Chrome CDP 端口 9224：'tests/rank-rewards.cjs'、'tests/challenge-boss.cjs'、'tests/challenge-volumes.cjs'、'tests/challenge-verification.cjs'。同一时间顺序运行，避免导航互相干扰。

## GitHub + Render 公网部署

1. 将本文件夹中的 HTML、CSS、JavaScript、SVG 资源、`render.yaml`、`.gitignore` 和 `README.md` 提交到自己的 GitHub `sing` 仓库根目录。
2. 登录 <https://dashboard.render.com/>，选择 **New → Blueprint**，授权 GitHub 并选择 `sing` 仓库。
3. Render 会读取 `render.yaml`，创建名为 `sing` 的 Static Site，确认部署。
4. 部署成功后，使用 Render 显示的 `https://….onrender.com` 地址访问。实际子域名由 Render 分配，不一定是 `sing.onrender.com`。

也可以选择 **New → Static Site** 手动连接仓库：Build Command 填 `echo "Static site ready"`，Publish Directory 填 `.`，Root Directory 留空，开启 Auto-Deploy。

站点由 Render 托管，不需要本机保持开机、开放端口或配置局域网。后续推送 GitHub 会自动更新。公网访问仍取决于访问者网络能否连接 Render，并不保证所有地区或网络均可访问。

## 更新与缓存

HTML 中的本地 CSS/JS 引用带内容摘要版本参数，防止部署时旧页面资源缓存与新脚本混用。修改对应资源时，同步更新其 `?v=` 参数（文件 SHA-256 的前 12 位）。Render Blueprint 配置要求资源每次使用前重新验证缓存；已有手动创建的站点需同步配置 `Cache-Control: no-cache, max-age=0, must-revalidate` 响应头。

## 完整作品学习

学习模式只纳入全文条目，题库中明确标注「节选」的内容不进入学习列表。六类各 50 篇，共 300 篇完整作品；汉赋含设论体，元曲采用独立小令及带过曲。学习卡片显示「一共 50 篇，目前已经学习 X 篇」，已学篇数按完整学完的作品去重并自动保存。扩充前的有效存档保留原顺序和位置，新增作品接在原书目后；校正文句会从当前篇预习开始。《诗经》《楚辞》全文补齐依据 [chinese-poetry 公开古典诗文数据](https://github.com/chinese-poetry/chinese-poetry)，保留原作标点；古诗文存在异文，以题库所收文本为准。

顶部品牌名称为普通标题，不再作为刷新或返回首页的链接。
